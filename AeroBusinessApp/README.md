# AeroBusinessApp

Практическое занятие №3: дизайн окон WPF, оформление кнопок и навигации.

## Запуск

1. Откройте `PZ3_WPF.sln` в Visual Studio.
2. Убедитесь, что установлен .NET Framework 4.8 Developer Pack.
3. Запустите проект через `F5`.

## Реализовано

- общий стиль всех кнопок в `App.xaml`;
- стили `TextBlock`, `TextBox`, `PasswordBox`;
- логотип и иконка приложения находятся в папке `Resources`;
- страница авторизации `Pages/Autho.xaml`;
- страница клиента `Pages/Client.xaml`;
- переход на страницу клиента по кнопке «Войти как гость»;
- кнопка «Назад» отображается только когда возврат возможен;
- проверка пустых полей логина и пароля;
- масштабируемая компоновка и минимальный размер главного окна.
